# What Really Happens When You Make an HTTP Request

## Local ReactJS Frontend → AWS EC2 Node.js Backend

```mermaid
flowchart LR
    A["Local laptop<br/><br/>ReactJS Frontend<br/><br/><b>127.0.0.1:3000</b>"]
    B["AWS EC2 instance<br/><br/>Node.js Backend<br/><br/><b>10.0.0.1:443</b><br/><br/>https://api.example.com"]

    A -->|"HTTP GET /profile"| B
    B -->|"HTTP response 200 OK {data}"| A
```

- **127.0.0.1:3000** as Source IP
- **10.0.0.1:443** as Destination IP (This is public availble)
